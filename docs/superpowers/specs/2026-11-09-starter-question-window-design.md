# 企业 RAG 前端细节修复设计

## 目标

将预设问题编辑改为同款评估浮动窗口并缩小四个操作按钮，恢复企业 RAG 页头结构；同时只重排企业 RAG 六边形评分细则卡片，使其完整采用当前建设评估的设计规格。评分算法、权威数据、证据合同和领域语义保持不变。

## 已批准的界面行为

- 点击欢迎气泡左下角的铅笔，打开共享 `RagAnswerWindows` 中的“预设问题”窗口。
- 桌面端沿用同款居中浮窗、拖动、缩放、放大、关闭、Escape 和焦点归还；移动端沿用同款 bottom sheet。
- 不复制一套近似窗口，也不保留旧 Radix Popover。
- 窗口正文继续展示正式题、草稿、编辑输入、生成中和错误状态；保存、换一批、取消的服务端行为不变。
- 删除仅在已有正式题且无草稿时出现的“编辑并确认后，才会替换当前问题。”；“新问题草稿已生成，确认后才会替换当前问题。”等有实际状态含义的提示继续保留。
- “编辑问题 / 换一批 / 取消 / 确认使用”使用与初始问题一致的 13px 字号、20px 行高、常规字重、约 32px 高度、`3px 10px` 内距、9px 圆角和 0.5px 边框；主按钮继续紫底白字，其他按钮保持现有层级。
- 保留不小于约 44px 的可点击命中范围，不以视觉尺寸牺牲触控可用性。

## 页头恢复与非目标

- 企业 RAG 页面继续只显示一套页头：左侧“让回答真正满足用户需求”及“用企业资料回答客户问题，核对回答依据，找到改进方向。”；右侧“评分规则 / 评估记录”。
- 增加结构和顺序回归断言，并在正式环境验证位置；不增加任何新小字。
- 不修改六边形几何与评分、仪表盘、客户任务结果卡、自动评估、知识状态、历史删除、starter API 或数据库。
- Core 继续使用正式版本 `d41158b178ebf75e0a8d4c58c498989a0745fa56`，本轮只发布 Brand Module。

## 企业 RAG 六边形评分细则

- 六个真实 `button` 默认全部收起；同点再次点击收起，切换点时只显示新维度。新 `report/reveal key`、空问题状态均清空旧详情，交互后焦点保留在触发圆点。
- 保留现有雷达几何、圆点坐标、维度百分比计算和 44×44px 触控区；空问题继续禁用。
- 详情使用 `role="region"` 与“{维度名称}详情”，圆点保留 `aria-expanded/aria-controls`；分数和每个状态提供完整 `aria-label`。逐字动画继续给屏幕阅读器提供一次完整文本。
- 卡片采用指定玻璃材质：`rgba(255,255,255,.72)`、20px blur/180% saturation、0.5px 浅边框、20px 圆角、`0 8px 24px rgba(29,29,31,.08)` 阴影及 `14px 16px 16px` 内距；距雷达 12px。
- 顶部统一为 `minmax(0,1fr) auto` 网格：16px 常规字重标题与右侧得分/权重垂直居中，下方为 0.5px 分隔线。删除固定检查项数量和其他辅助标题文案。
- 得分格式统一为整数无小数、非整数最多一位小数，真实 0 显示 `0`；待核验和不适用继续显示文字状态。雷达百分比只调整显示格式，不改变计算。
- 权威 checklist 按原始顺序、原始数量完整渲染。每项为左侧标题与摘要、右侧双圆状态的两列网格；不使用小卡片、胶囊或项目分割线。
- 每项保留原始得分/权重、rationale、归一化说明、finding 摘要及影响、可公开声明；继续隐藏 evidence ID、`promise-*`、`audit:*` 和“证据：”等内部坐标。
- 状态继续区分满足、部分满足、不满足、待核验和不适用，并使用已批准的 14/6px 双圆配色与普通 13px 黑灰状态文字，不能只依赖颜色。
- 折叠继续使用 300ms grid/opacity/translate 动画；展开 300ms 后用 `step-end` 放开内部 overflow，避免阴影被裁切。数据揭示继续复用 800ms `useDataReveal` 与 `RagProgressiveText`。
- Reduced Motion 立即显示最终内容并关闭所有位移、折叠、数字与逐字动画；320、390 和 1440 视口不得产生横向溢出。
- 所有样式使用企业 RAG 专属作用域或明确 modifier；建设评估、报告页、人工评审、仪表盘及其他 RAG 卡片不受影响。

## 代码边界

- 扩展 `RagAnswerWindows` 的 panel 类型，新增独立 `starter` panel；移动端三评估标签仍只包含原三个评估 panel。
- 将预设题设置表单提取为有清晰 props 的组件，由 `EnterpriseRagPreview` 的同一个窗口实例承载，避免两个窗口层级竞争。
- `RagChat` 只保留欢迎题展示及铅笔触发器，不再拥有 Popover 外壳。
- 确认成功后关闭 starter 窗口；失败时保持窗口和输入；关闭后焦点回到铅笔按钮。
- `RagEvaluationRadar` 只调整详情交互复位、语义 DOM、显示格式和前端揭示；继续调用原有 `scoreRagChecklist`，不复制或修改评分逻辑。
- 优先复用现有 `useDataReveal`、`RagProgressiveText` 与状态双圆，不创建第二套实现。
