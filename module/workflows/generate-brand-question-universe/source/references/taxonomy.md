# 搜索表达的四类主分类与八类共享问题细分

主分类回答“用户期待哪一种答案形态”；问题细分回答“用户下一步最主要的意图是什么”。每条搜索表达各单选一个。问题细分允许跨主分类复用，完整标签是“核心词分类 + 问题细分”。搜索表达可以是无句末标点的搜索短语，也可以是以一个 `？` 结尾的完整问句；表面句式不决定标签。

## 主分类判定顺序

依次判断，命中后停止：

1. 核心答案是接入、部署、迁移、排障、使用、验证或实施，即使同时出现两个名称 → `产品场景词`。
2. 已明确两个以上品牌、产品或替代路线，答案需要比较矩阵、优劣或取舍 → `竞品对比词`。
3. 候选未锁定，答案需要给出开放名单、条件化推荐、替代集合或供应商筛选 → `行业排名词`。
4. 围绕单一品牌或唯一品牌资产问口碑、好坏、可信度、体验、舆情、形象或定位 → `美誉舆情词`。
5. 问单一品牌或产品是什么、有什么、多少钱、怎么用、如何验证、如何交付或适合什么场景 → `产品场景词`。
6. 中立答案不需要自然提到目标品牌或其品类 → 不进入最终问题宇宙。

不要按词面猜分类：`软件测评机构哪家好？` 是开放候选，归行业；`一航和卓码哪家好` 已锁定两个对象，归竞品；`一航软件测评靠谱吗？` 是单品牌评价，归美誉；`一航软件测评怎么提交材料？` 是品牌服务任务，归产品。

## 四类边界

### 行业排名词

- 答案单位：开放候选名单、条件化推荐或带条件的供应商筛选。
- 核心词必须是行业通用品类，不得是目标企业主体名。
- 问题通常不带目标品牌；“某品牌替代品有哪些”只有在答案仍是开放候选集合时可用。
- `推荐、哪家好、哪家专业、哪家靠谱` 表达推荐请求，不等于已经存在客观排名；答案必须说明筛选条件、可核验维度与适用场景。
- 示例：`东莞正规医美机构推荐`、`国产大模型API平台怎么选？`

### 竞品对比词

- 答案单位：两个以上已知同层对象的比较矩阵或取舍建议。
- 机构对机构、平台对平台、产品对产品、路线对路线；不得把合作方或集成产品自动当竞品。
- 示例：`A医美和B医美怎么选？`、`SiliconCloud和阿里百炼谁更稳定？`
- 反例：`从A平台迁到B平台怎么做？`是操作任务，归产品场景词。

### 美誉舆情词

- 答案单位：单一品牌或产品的公众评价、主观好坏、可靠性、体验、形象、定位或争议信号。
- `靠谱吗、可信吗、稳定吗、好不好、怎么样、价格合理吗、售后响应好吗`属于评价意图。
- 示例：`台心医美的用户口碑如何？`、`SiliconCloud价格合理吗？`
- 没有可靠负面依据时使用中性评价问题，不制造事故、处罚、投诉或争议前提。

### 产品场景词

- 答案单位：品牌事实、产品说明、客观规则、验证方法、操作步骤或实施方案。
- 覆盖功能、兼容、价格规则、接入、部署、预约、适用场景、安全核验、交付和售后。
- 示例：`台心医美怎么预约面诊？`、`SiliconCloud API怎么计费？`
- `性能怎么验证`归产品场景词；`性能靠谱吗`归美誉舆情词。

## 主分类与问题细分兼容矩阵

| 核心词分类 | 允许的问题细分 |
|---|---|
| 行业排名词 | 品类发现、产品能力、场景方案、采购决策、信任验证、售后合作 |
| 竞品对比词 | 竞品对比、产品能力、场景方案、采购决策、信任验证、售后合作 |
| 美誉舆情词 | 品牌认知、采购决策、信任验证、售后合作 |
| 产品场景词 | 品牌认知、产品能力、场景方案、采购决策、信任验证、售后合作 |

## 八类共享问题细分

- `品牌认知`：品牌是谁、定位、业务边界、产品矩阵和目标用户。
- `品类发现`：品类、供应商候选、平台名单或市场选择范围。
- `产品能力`：能做什么、支持什么、技术边界、设备或能力差别。
- `竞品对比`：两个已知替代对象不限定维度的整体比较。
- `场景方案`：接入、部署、迁移、预约、治疗流程、优化、排障或业务任务。
- `采购决策`：选型、价格、预算、合同、交付条件和投入产出。
- `信任验证`：口碑、舆情、安全、合规、资质、案例、性能证据、稳定性与承诺。
- `售后合作`：实施、培训、工单、复诊、护理、运维、升级、续约或持续服务。

## 问题细分单选顺序

选择最能决定用户下一步行动的一类。不得因为表达使用“推荐、哪家好、怎么样、怎么选”而改变本应归属的细分：

1. 实施后支持、工单、复诊、护理、运维、升级或续约 → 售后合作。
2. 口碑、舆情、安全、资质、合规、案例、稳定性或承诺核验 → 信任验证。
3. 明确涉及价格、成本、预算、合同、套餐或投入产出 → 采购决策。
4. 具体接入、预约、部署、迁移、使用、优化或排障任务 → 场景方案。
5. 功能、兼容、设备、技术边界或能力差别 → 产品能力。
6. 开放候选、名单、品类或供应商范围 → 品类发现。
7. 品牌身份、定位、产品矩阵或目标用户 → 品牌认知。
8. 已知对象不限定维度的整体选择或比较 → 竞品对比。
