# Brand 双 HTML 报告工作流

当前版本：report-v3-web-html-2。上游参考：FrontMind_Report_Workflow_一键交付版_v3_最终版.zip。

选择资料卡 → S1–S4 研究 → S4.8 核心产品/双问题 → 唯一确认卡 → S5.0 每问题每平台5次真实采集 → 诊断与策略 → 两份 HTML。

有效主控、阶段与共享契约在 source/active/；source/Strategy_Workflow 下的原方法、schema和脚本标为历史参考，不进入模型归档，不在网页运行。SOURCE_MANIFEST.json 保留上游身份、当前文件哈希和有效文件清单，构建逐项验证。

执行引擎为官方 DeepSeek Harness 0.2.0-rc.2，模型 deepseek-flash。迁移仅覆盖报告；不创建旧 XTY/Codex Agents 报告任务。持续保存正文、工具调用/结果、来源、中间文件和错误；刷新按游标恢复。用户停止后不追加新采集，恢复沿用付费请求标识。

最终仅 panorama.html 与 briefing.html。全景完整承接研究正文；汇报使用13个商业主题，以自然增长HTML段落承载原汇报逻辑，并融合整体/分类排名、Q2风险、信源、明细及指标解释。两个文件统一冻结数据，Q1独占排名分母，Q2只分析风险信任。缺乏结构化竞品或内容分类位次时不造榜。中间文件仍可访问。

正文由安全Markdown渲染，外链仅限HTTP(S)，下载HTML自包含无外部脚本和字体请求。完整性检查保证研究阶段、唯一样本、确认范围和每问题每平台5条；最终需桌面/窄屏真实预览、刷新恢复、展开、下载与数字核对，不以构建代替验收。
