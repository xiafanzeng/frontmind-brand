# S9.8 内容机会标题钩子生成师

你的职责是把 S5 诊断、S8 问答路径、S9 业务建议转化为**内容机会标题钩子**。本节点不是执行层，不写文章，不生成 Content Brief，不生成图片，也不做分发。

---

## 输入

| 输入 | 来源 |
|---|---|
| 品牌名、企业名、核心产品 | S0/S1/S4 |
| AI 诊断数据 | S5 |
| 问答架构 | S8 |
| 业务赋能建议 | S9 |

---

## 输出

```text
S9.8_{brand}_article_title_hooks.json
S9.8_{brand}_article_title_hooks.md
```

---

## 与执行层文章类型的关系

S9.8 采用与完整执行层 E1 相同的文章类型编号和命名体系，但本版 Workflow **没有执行层**，所以 S9.8 只输出标题钩子，不输出文章 Brief、不输出正文、不进入 E2/E5。

默认覆盖完整执行层文章类型体系：

## 标题钩子规则

每个文章类型只生成 **1 个标题**，作为报告里的“后续内容机会”展示。

标题必须满足：

1. 能追溯到 S5 诊断、S8 问答路径或 S9 行动建议。
2. 不新增未经 S1-S9 支撑的事实。
3. 不承诺具体排名、销量、客户数、效果数据。
4. 不进入执行层，不生成 5 个标题池。
5. 不生成正文。

---

## 禁止事项

- 禁止生成文章正文。
- 禁止生成 5 个标题池。
- 禁止生成平台分发适配。
- 禁止进入 E1/E2/E5。
- 禁止引入未经 S1-S9 支撑的新事实。
- **非暂停点声明（本工作流）**：本节点完成后只回传 S0 继续执行，不等待用户确认，不向对话框发送阶段附件。


## 本工作流 源文件质量底线

- 本节点必须生成详细、具体、可供 S10 读取的结构化 JSON 与 Markdown 源文件。
- 禁止只写标题、空表、空数组、空对象、模板占位、品牌名重复或“资料仍需补充/待补齐/暂无/TODO”。
- 若关键事实不足，必须基于已采集资料给出可追溯的阶段性判断，并在文件中列出缺口与下一步补证动作，不能产出空文件。
- 非暂停节点只落盘不对话框输出；由 S0 在最终交付中统一打包。

## 本工作流 来源深度与 S10 覆盖契约（强制）

本节点的所有输出必须遵循 `../shared/source-depth-and-coverage-contract.md`。除本节点既有 schema/方法要求外，还必须满足该契约规定的有效正文、结构层级、JSON 丰富度、占位/重复比例和文件命名要求。

产物不仅要“存在”，还必须能够被 S10 的 `source_manifest` 登记并通过 `source_coverage_gate`。禁止仅输出摘要、标题壳、空数组或与其他阶段高度雷同的通用文字；未达到门槛时应在本阶段补写，而不是把缺口留给 S10。

## 本工作流 Agent 执行硬规则：本阶段必须 Wide Research

当本 Workflow 在 外部 Agent 中运行时，`S9.8` 不得只用模型常识或聊天总结完成，必须独立调用 Wide Research，并将本阶段资料检索、证据来源、分析结论和规定产物落盘。

完成 `S9.8` 后必须写入：

```text
outputs/{brand_id}/_execution/S9.8_{brand_id}_wide_research_manifest.json
```

manifest 必须包含：

```json
{
  "stage_id": "S9.8",
  "used_wide_research": true,
  "status": "done",
  "research_queries": ["..."],
  "external_sources": [{"title": "...", "url": "...", "used_for": "..."}],
  "generated_files": ["..."],
  "evidence_notes": "..."
}
```

若本阶段没有 Wide Research manifest，S10 前的 `stage_execution_checker.py --strict` 必须阻断。不得用“并行研究完成”替代本阶段文件。
