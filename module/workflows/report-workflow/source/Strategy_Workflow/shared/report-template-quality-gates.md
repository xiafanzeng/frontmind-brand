# FrontMind 报告模板质量门禁 本工作流

## S5 数据文件门禁

- 使用专业证据模板，不显示表格解析日志或内部处理记录。
- 首页包含监控问题汇总；后续逐条展示平台、轮次、答案原文、答案实际引用与检索参考来源，两者分开标注。
- 不强制生成记录索引页，优先保证逐条答案明细完整。
- 每条记录必须是答案明细块；不得生成截图页。
- PDF/HTML 为客户可读清洁视图，内部 JSON 保留原始表格提取结果。

## S10 主报告门禁

- 唯一官方封面模板为 `S10.AI智能品牌优化方案全景报告生成师.skill/templates/frontmind_cover_front_back.pdf`：必须恰好 2 页 A4，固定 SHA-256 为 `e37c51f793649fcf561c80d80b4b80ae1f70c470ec8a6956523b1795f369872d`。
- 客户 HTML 必须用官方 PDF 第 1 页的内容哈希安全预览替换旧 HTML 渐变封面；HTML 不追加封底。最终 PDF 必须按“官方第 1 页 + 去除 HTML 预览后的正文 + 官方第 2 页”组装。
- 生产执行禁止 `--no-cover-stitch` 和 `--keep-html-cover`。S11 未传 `--cover-pdf` 时仍须自动定位固定模板，不能降级为 `no external cover`。
- 使用 11 个正式分部的页级模板；页数随内容自然增加，不能为了压缩页数删减获准展示的内容。
- 图表先于原始表格，所有图表必须由真实上游数据生成，缺数据时不得用占位图。
- S3 以趋势评分、机会含义和优先级表呈现，不生成趋势机会坐标图；S5.5 五维评分有数据时必须生成维度达成度条形图。
- S4 差异化矩阵必须包含真实品牌/竞品值，并带 `data-differentiation-matrix` 标记；不得生成竞品心智地图。
- 独立信源/引用分析表必须在语义资产审计下半部分生成 Top 信源条形图、高频问题及代表性信源/内容表格；客户版不得显示三层对账/集中度 KPI 或模型引用量图表。
- 两张信源/引用图必须使用带语义标记的 paired 分页组，从新页开始并保持“两个标题、两个图形、两段说明”同页；单图降级为 stacked，但单张图卡仍不可拆。S11 必须兼容迁移旧版普通图表网格。
- 禁止省略号填充、跨客户样例字段、原始 HTML、上游文件名或来源 `h1`、内部头注、本地绝对路径、内部任务字段。
- 来源正文中的“危机与错误信息回应模板”“下游注入规则”“重校触发条件”必须按标题边界整节过滤。保留的来源局部标题必须去除源文档编号；最终 11 个正式分部编号不得改动。
- 不允许只把 S1-S9 压缩成客户决策摘要；必须把各阶段判断、证据、结构化表格、行动项转写为客户可读的展开正文。必要时可在同一章节内保留“阶段内容展开”小节，宁可页数更多，也不能漏掉阶段内容。
- 12 周内容编排、标题钩子、语义资产、话语/视觉资产与风险管理必须位于第十部分 GEO 战略选择之前；标题钩子必须紧随日历，且不生成独立章节。
- 不设置“官网与第三方平台权重”或“信源生态”作为原始章节名；相关内容必须按术语闭环规范化为“官网与第三方信源权重”“品牌信源覆盖”等客户版表述后继续保留。

## 阻断条件

以下任一情况必须停止交付：

- S4.8 固定问题未确认；
- S5.0 数据文件未确认；
- 缺少独立信源/引用分析表、引用三层对账失败，或问答监控表与信源/引用分析表数据未随导入自动确认；
- S10 读取的监控成功记录不足预期，且未同时满足 `data_confirmation_status=confirmed`、`partial_accepted=true`、成功答案数大于 0；
- S5/S10 compliance checker 报错；
- PDF 未生成或为空；
- 官方封面文件缺失、非恰好 2 页 A4、SHA 不符，或客户 HTML 仍使用旧封面预览；
- 最终 PDF 第 1 页/最后 1 页的固定画布视觉指纹未分别匹配官方模板第 1/2 页，或出现双封面、缺封底、首尾颠倒、`no external cover`；
- 缺少 `citation_chart_gate`，或 Top 信源图标题与说明跨页；任何未通过该门禁的 S11 候选不得交付；
- 报告出现 `……`、`None`、`待补齐`、`暂无`、`taskId`、`reasoningProcess`、来源 `h1`、内部头注或本地绝对路径；
- 报告出现问答树问题清单、问题优先级与内容承接矩阵、30 条问题清单、质量与风险闸门、句式模板、危机与错误信息回应模板、下游注入规则、重校触发条件、趋势机会坐标图、竞品心智地图或标题钩子独立分隔页；
- 内容日历、标题钩子或差异化矩阵 marker 缺失，或三者顺序/数据不符合契约。
