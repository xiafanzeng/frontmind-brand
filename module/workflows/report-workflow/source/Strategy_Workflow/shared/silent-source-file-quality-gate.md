# Silent Source File Quality Gate 本工作流

本规则用于防止 S 阶段只生成空壳文件，导致 S10 全景报告出现空白页。

## 1. 非暂停阶段交付方式

- S1-S9.8 必须真实生成源文件，但不在对话框逐阶段输出附件。
- 只允许在两个全局暂停点和最终交付时面向用户发送确认或文件。

## 2. 每个 S 阶段的最低内容要求

每个进入 S10 的 Markdown 文件必须满足：

- 文件非空，且有效正文不少于 600 个中英文字；
- 至少包含 3 个有实质内容的小节或表格；
- 不得只有“{品牌名} XX报告”这类标题；
- 不得主要由“资料仍需补充 / 待补齐 / 暂无 / TODO / 示例 / 占位”组成；
- JSON 不得为空对象、空数组，关键字段不得全部为空字符串；
- S3、S4、S5、S8、S9 必须有可直接进入客户版报告的判断、表格或行动项。

## 3. S10 前置门

`pre_render_file_check.py` 与 `completeness_checker.py` 必须阻断空文件、占位文件和仅标题文件。S10 不得把缺失材料渲染成“本模块当前缺少…”页面，而应返回错误并要求补齐对应 S 阶段。

## 4. S5.0 监控数据文件

双表导入流程不生成截图资产。客户版 HTML/PDF 仅允许展示问题、平台、轮次、答案原文、答案实际引用、检索参考来源；两类来源必须分开。不得出现截图页、截图索引、截图 URL、本地截图文件等字段。
