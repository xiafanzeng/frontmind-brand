# FrontMind Strategy Workflow

本目录包含 S0-S11 的执行节点。本工作流的调度核心为：

1. 先阅读流程和暂停点逻辑（唯一暂停点 1；S5.0 双表导入自动确认后直接连跑）；
2. 每个研究型 S 阶段都调用 Wide Research 并落盘文件；
3. S5.0 只能通过墨力指数 API 自动取数生成并导入两份 `.xlsx`（AI 问答监控表和信源表/引用分析表），且不得模拟；两份表格缺一不可（路径B手动上传已移除）；
4. S10 必须深度嵌入 S1-S9.8；
5. S11 必须做成品格式整理。

企业名称是唯一必填项；其他缺失信息由 S0.1 规划并由 S1/S3/S4 Wide Research 有证据补全。

外部 Agent / 执行 Agent 运行时，必须先读根目录：

```text
00_先读我_全景报告最高原则.md
全景报告一键执行提示词.md
```

第一轮最多执行到暂停点 1。


## 术语与模板字段闭环

所有上游研究术语进入最终报告前，必须按 `Strategy_Workflow/shared/术语与模板字段闭环契约.md` 统一成客户版术语。术语规范化不得删除阶段内容。
