# S5.0 用户上传引用分析表格契约

用户在暂停点 1 确认固定双问题后，除 AI 问答监控表外，还必须上传一份独立的信源表（引用分析表）`.xlsx`。两份表格缺一不可。

## 1. 双表输入

S5.0 必须收到两个不同用途的 `.xlsx` 文件：

1. **AI 问答监控表**：按 `uploaded-monitoring-spreadsheet-contract.md` 导入；
2. **引用分析表**：按本契约导入。

推荐命令：

```bash
python3 Strategy_Workflow/S5.品牌诊断专家.skill/scripts/import_citation_analysis_spreadsheet.py \
  --brand "{brand_id}" \
  --brand-name "{brand_name}" \
  --spreadsheet "{uploaded_citation_analysis_xlsx_path}" \
  --output-dir "outputs/{brand_id}/02_monitoring_data"
```

缺少任一表格、文件格式错误或三层数据无法对账时必须停止，不得补造引用记录。两个文件均通过导入后自动写入 `data_confirmation_status=confirmed`（本工作流不设数据确认暂停点），直接进入 S5 及后续阶段。

## 2. 工作簿结构

工作簿必须包含以下三类 Sheet。Sheet 名可有轻微差异，导入器以表头识别逻辑类型。

### 2.1 媒体引用分析

| 必需字段 | 含义 |
|---|---|
| 域名 | 被引用信源域名 |
| 媒体名称 | 信源展示名 |
| 引用次数 | 该信源被引用的次数 |
| 引用占比 | 该信源引用次数占总引用次数的比例 |

### 2.2 内容引用分析

| 必需字段 | 含义 |
|---|---|
| 文章标题 | 被引用内容标题 |
| 媒体名称 | 内容所属媒体 |
| 媒体 URL / 媒体url | 内容所属域名 |
| 文章 URL / 文章URL | 被引用内容链接 |
| 引用次数 | 该内容被引用的次数 |
| 引用占比 | 该内容引用次数占总引用次数的比例 |

### 2.3 问题引用分析

| 必需字段 | 含义 |
|---|---|
| 模型 | 产生引用的 AI 模型或平台 |
| 监控问题 | 触发引用的问题 |
| 文章标题 | 被引用内容标题 |
| 文章链接 | 被引用内容链接 |
| 媒体名称 | 被引用信源名称 |
| 引用日期 | 引用记录日期 |

## 3. 强制对账

导入器必须验证：

```text
媒体引用分析的引用次数合计
= 内容引用分析的引用次数合计
= 问题引用分析的数据行数
```

同时记录：

- 媒体数、内容记录数、唯一文章 URL 数；
- 模型数、监控问题数、引用日期范围；
- Top 5 / Top 10 信源集中度；
- 模型引用量、问题引用量、高频引用信源与高频引用内容；
- 内容层与问题层唯一文章 URL 是否一致。

引用占比列只作原表展示校验。内容层可能有大量低频记录，逐行保留两位百分比后合计会明显低于 100%；报告必须以引用次数重新计算占比，并把原表占比合计异常记为警告而非伪造补差。引用次数不得为负数；模型、问题、链接、日期和计数字段不得为空。媒体名或文章标题缺失时可使用域名/链接作为展示标签，但必须记录标准化警告。

## 4. 标准输出

```text
S5_{brand}_引用分析数据.json
S5_{brand}_引用分析原始提取.json
S5_{brand}_引用分析导入摘要.md
S5_{brand}_citation_analysis_confirmation.json
uploaded_sources/S5_{brand}_citation_analysis_source.xlsx
_execution/S5.0_{brand}_citation_analysis_import_manifest.json
```

其中：

- `引用分析数据.json` 是 S5.5 和 S10 使用的紧凑结构化数据；
- `引用分析原始提取.json` 保留三层原始行，供内部追溯；
- 导入摘要不替代 S5.5 的语义资产审计；
- 最终客户报告仅呈现汇总、图表、代表性内容与行动建议，不嵌入全部原始行。

## 5. 确认与报告规则

- 本工作流不设数据确认暂停点：导入并通过三层对账后，脚本自动写入 `data_confirmation_status=confirmed`；
- S5.5 必须消费该文件，把“品牌信源覆盖与引用结构”放在语义资产审计下半部分；
- S10 仅在引用分析数据已确认、通过对账时渲染该模块；否则不得渲染占位信源模块。

## 6. 解释边界

- 引用次数代表“被使用频率”，不自动等于权威性、正面评价或事实正确；
- 引用集中度用于判断依赖结构，不直接等于风险等级；
- 模型引用量受问题量、监测周期和平台采样范围影响，跨模型比较必须同时披露样本口径；
- 只有表格明确提供或 S5.5 有独立证据支持时，才可把信源标为官方、权威、正面或负面。
