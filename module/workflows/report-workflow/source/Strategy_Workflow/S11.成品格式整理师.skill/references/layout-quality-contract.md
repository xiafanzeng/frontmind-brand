# S11 版面质量判定口径

- 官方模板：仅允许 `S10.AI智能品牌优化方案全景报告生成师.skill/templates/frontmind_cover_front_back.pdf`，必须恰好 2 页 A4，SHA-256=`e37c51f793649fcf561c80d80b4b80ae1f70c470ec8a6956523b1795f369872d`。
- HTML 封面：客户 HTML 必须使用官方第 1 页的哈希命名安全预览替换旧渐变封面；HTML 不追加封底。
- PDF 页序：必须是“官方第 1 页 + 去除 HTML 预览页后的正文 + 官方第 2 页”。禁止 `--no-cover-stitch`、`--keep-html-cover`、双封面、正文直出和 `no external cover`。
- 首尾指纹：最终 PDF 第 1 页和最后 1 页须在固定 DPI、固定 A4 画布上栅格化，并分别匹配模板第 1/2 页视觉指纹；指纹门必须由独立 checker 重验。
- 空白页：除封面/封底外，页面可见文本少于 25 个字符，且有效内容纵向占用低于 4%；整页白色背景和重复页脚不计入内容。**独立整页章节分隔页不算空白页**。
- 稀疏页：剔除整页白色背景与重复页脚后，页面有效文字和图形的纵向占用低于 32%，同时可见文本少于 420 个字符。**独立整页章节分隔页不算稀疏页**。
- 章节分隔页：**必须单独占据一整页**，只放分部编号、中英文标题与一句简述，其余留白，正文从下一页开始；分隔页在最终呈现前不得优化或压缩，不得与正文共页。S11 在检测空白/稀疏页时会自动识别并豁免这类页面。
- 表格：表头可重复；单行保持整体；整张长表允许跨页。
- 卡片：短卡片保持整体；超过约 700 字符的卡片必须允许跨页。
- 信源/引用图表：Top 信源图必须带 `data-citation-chart-group="true"`、`data-pagination-policy="keep-together"`，使用 stacked 模式；`.citation-chart-item` 的标题、图形和说明不得拆页。旧版普通 `chart-grid` 必须在 S11 中自动迁移。
- 引用图表 PDF 门：必须从实际 PDF 提取页码，确认 Top 信源图标题与说明同页。任一失败的 balanced/aggressive 候选直接淘汰；S11 QA 与独立复核都必须记录 `citation_chart_gate.required=true`、`citation_chart_gate.passed=true`。
- 正文：字号不低于 8.8pt，行距不低于 1.45。
- 阶段来源报告标题：最终 HTML/PDF 不得出现 `.source-stage-block h1` 或其他上游来源文件一级标题；来源正文直接进入客户版章节结构。
- 章节数：保留 11 个正式分部；“内容标题钩子”是“12 周内容编排”后的同章小节，不生成独立分隔页。
- 结构保真：差异化矩阵必须保留 `data-differentiation-matrix` 真实渲染标记；趋势机会坐标图、竞品心智地图、问答问题清单、问题优先级与内容承接矩阵、质量与风险闸门和句式模板不得出现。
- 客户版删项：危机与错误信息回应模板、下游注入规则、重校触发条件不得出现；保留的来源局部标题须剥离编号，正式 11 分部编号不变。
- 客户清洁度：不得出现阶段输出头注、版本/日期/输入/原则/数据源说明、上游文件名或 Unix/Windows 本地绝对路径。
