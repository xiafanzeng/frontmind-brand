# S9 业务赋能与行动路线

综合 S1–S8 做问题优先级矩阵：问题—证据—GEO影响—严重度—置信度—动作。行动清单包含优先级、具体产物、负责人/协作方、依赖、时间、验证指标、风险和预计业务意义；有官网/Schema缺口时写具体承接动作，不套固定模块菜单。明确前 12 周/3个月与6个月里程碑，当前实测、方案目标和验证方法分列，所有目标注明需后续复测，不能保证提升百分比。列企业侧和服务侧分工、审批/事实核验、持续监测及调整节奏，整个计划适用于本研究主体。

输出完整阶段正文与真实来源，遵循 MASTER_CONTROL.md、SHARED_CONTRACT.md 和当前 OUTPUT_SCHEMA.json。

## 八类问题证据与完整行动表

问题总结逐项覆盖：S1事实/案例/资质/合规；S2意图与表达错位；S3趋势和品类词机会；S4定位/差异/可信理由；S5可见度/位次/风险/信源；S5.5实体与语义一致性；S6表达token与禁用语；S7/S8视觉、问题路径及落地承接。不适用项说明依据，不能编造问题。

问题优先级矩阵列问题编号、证据来源、影响、严重度、置信度与建议方向。行动表逐项保留action_id、title、problem_linked、priority(P0/P1/P2)、reason、expected_business_effect、owner_hint，并补协作方、依赖、产物、期限、里程碑、KPI基线/方案目标/验证方式及风险。行动域为实体事实、AI可见度、问答资产、定位话语、网站Schema、分发引用，分别用GEO_A1_entity_facts、GEO_A2_ai_visibility、GEO_A3_qa_assets、GEO_A4_positioning_language、GEO_A5_site_schema、GEO_A6_distribution_citations。官网缺口必须写成具体承接动作，不做无依据套餐。
