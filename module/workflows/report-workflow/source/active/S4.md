# S4 品牌定位

围绕主体的核心服务/产品确定竞争边界与用户任务，列有证据的竞品/标杆及差异化矩阵，每格标明可核查事实、推断或缺证。形成目标人群、品类归属、差异价值、证据支撑的定位声明，避免“唯一/第一/最好”等无法证明的绝对化表述。完整写功能、情感、自我表达价值三角及定位与 S2 意图/S3 趋势的关系。明确定位适用边界、核心服务候选与证据；products 此阶段为空，候选在正文供 S4.8 复核。

输出完整阶段正文与真实来源，遵循 MASTER_CONTROL.md、SHARED_CONTRACT.md 和当前 OUTPUT_SCHEMA.json。

## 定位验证与差异化矩阵

保留目标人群—品类归属—差异价值—证据四要素及功能/情感/自我表达价值三角。差异化矩阵正常覆盖至少5个真实竞品/标杆、5个有证据的比较维度，逐格标事实与来源；无法验证的值明确缺口，不据此推断竞品劣势。完整解释差异对用户选择的含义，并验证意图匹配、痛点覆盖与趋势对齐。主张必须连接证据，避免无依据的“唯一”措辞。客户正文不展示缺乏定量依据的心智地图。
