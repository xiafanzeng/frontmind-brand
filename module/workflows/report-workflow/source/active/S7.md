# S7 视觉符号体系

先审查 S1 实际获取的视觉资产。已有 logo、色值、字体/图像风格优先继承，缺失时区分“未取得”和“建议推导”，不能假称真实提取。给视觉母题、颜色(真实或建议的 hex)、字体层级、图形/照片规则、渠道场景、窄屏与无障碍建议、可执行 Prompt 规格；每条方案连接 S4 定位与 S6 话语。不在本阶段声称已生成图像。医疗图像不以示意图冒充诊疗前后对比或真实患者案例，记录授权与事实边界。

输出完整阶段正文与真实来源，遵循 MASTER_CONTROL.md、SHARED_CONTRACT.md 和当前 OUTPUT_SCHEMA.json。

## 完整视觉规格

三层结构为基础识别（标志/颜色/字体/留白）、传播组件（版式/图像/图标/图表）、场景应用（官网/科普/社媒/证据资料）。提炼3–5个有定位依据的视觉母题；每条Prompt包含母题、主体、构图、光影、hex色值、比例、应用场景、禁用元素与资产依据。既有资产审计与建议设计分列，缺真实资产不能假称现有VI。用长表保留跨场景应用和风险边界。
