# S3 品类趋势

锁定本研究主体的细分品类与地域边界，判断品类成熟度及差异化机会。优先复用 S1 的已读信号，仅增量研究缺失、过时或需要专业证据部分。分析需求、供给、文化、政策与技术；对每条趋势写来源日期、证据、影响方向、机会/风险、置信度、优先级与评分依据。区分已发生变化和研究推断，不虚构市场规模、增速与预测。给品牌可执行的趋势应对，不生成无数据的机会坐标图。

输出完整阶段正文与真实来源，遵循 MASTER_CONTROL.md、SHARED_CONTRACT.md 和当前 OUTPUT_SCHEMA.json。

## 必备栏目与趋势卡

包括品类边界/分化、PEST、竞争五力、需求与供给、技术、消费、政策、文化弱信号、生命周期、机会/风险和品牌应对。正常研究至少8条有差异的趋势，每条至少2个独立信号源并标时间；信号不足的趋势只能作为待验证假设，并具体记录查询和缺口，不虚构第二来源。趋势表列趋势ID、信号、类型、阶段、证据链接/日期、影响、紧迫度、可行动性、置信度、优先级与评分理由。评分是研究判断，不称行业实测。
