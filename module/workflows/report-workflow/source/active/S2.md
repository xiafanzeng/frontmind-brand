# S2 营销图谱

从 S1 事实推导用户角色—任务—场景—触发—查询意图—决策因素—内容触点，逐行语义一致，不能按数组索引轮转或笛卡尔积凑数。区分品类拦截与品牌验证。列出受众、场景、搜索意图分层、决策阻力、问题路径与内容承接表。
按本研究主体和地域调查真实竞品/标杆，分别说明任务重叠、差异、公开依据与判断；缺证据不以模板套话补满。S2 是意图研究，不增加后续付费监测问题，固定 Q1/Q2 由 S4.8 生成。至少覆盖从认知到考虑、决策、使用、推荐的完整路径，行业不适用阶段要解释。

输出完整阶段正文与真实来源，遵循 MASTER_CONTROL.md、SHARED_CONTRACT.md 和当前 OUTPUT_SCHEMA.json。

## 完整正文与长表

1. 用户画像矩阵：角色、需求、核心痛点、决策责任、影响者、付款者、信息渠道、事实依据。
2. 场景矩阵：业务/决策/使用/服务场景，触发条件、地域/时段/约束、真实任务、阻力、决策标准。
3. 用户—场景—意图三元组长表：编号、用户、场景、触发、搜索意图、查询模式、决策因素、内容触点、证据。原方法建议约30条有效组合；只保留真实且有意义的组合，不按数量凑表。
4. 核心话题与子场景：聚类主题、痛点、关联三元组、角色、触发、问题模式、内容承接。区分 informational/comparative/transactional/navigational，区分品类拦截和品牌验证。
5. 关键词体系：核心词、长尾词、风险词、使用场景与内容触点。没有真实指数时只做定性意图判断，不虚构搜索量。
6. 竞品/标杆表：针对本主体和地域公开检索实际竞争者，广泛扫描候选；证据不足时记录已验证范围与缺口，不填无关机构。分别给业务边界、任务重叠、差异、来源与判断。

所有表格逐行审阅角色、任务、触发与决策因素的对应关系，保留完整有效结果，不只放前三条或摘要。

正常研究范围保留原流程深度：至少3种真实角色、30个语义一致的有效三元组、12个有差异的子场景，并对真实竞品进行公开扫描。先达到证据覆盖再形成表格；若某项客观不适用或无法查证，逐项说明已查来源、实际覆盖和缺口，不能造角色、重复表格或无关竞品凑数。
