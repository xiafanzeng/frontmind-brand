# 当前阶段产物、数据与质量契约

## 模型输出
只返回 OUTPUT_SCHEMA.json 要求的 JSON。operationToken/inputHash 原样回填。研究阶段输出 stage={id,title,summary,markdown,sources} 与 products；S4.8 的 products 是 1–8 个有已完成研究证据的核心产品候选，question 必须恰为 label+推荐，其他阶段 products=[]。汇报阶段输出 slides 的 13 个商业主题，每项 title/lead/bullets/sourceStageIds。内部字段名 slides 是兼容契约，呈现为自然增长的 HTML 段落，不限制页数。

## 研究正文
summary 只是进展摘要，markdown 必须完整保留本阶段所需的结论、依据、表格、含义与执行动作，不能以“详见文件”替代正文。所有事实有可追溯来源；企业自述、独立公开证据、研究推断、方案建议分层标注。不确定内容标明原因与补证动作。不为达到字数机械扩写，不使用重复段落、占位文本、凑数表格。用户能展开完整阶段正文并访问中间文件。

复用已获取来源而非重复下载。同阶段来源列表为实际已读、能支撑判断的公开 HTTP(S) 链接，不以搜索结果标题冒充读取全文。医疗等受监管领域不得将通用资质推导为具体诊疗许可，不宣称保证效果，明确事实核验与诊疗评估边界。不要输出隐藏思维链；展示研究动作、证据和结论即可。

## 真实数据
monitoring 是唯一监控基线，历史报告仅作结构参考。Q1=questions[0] 是未点名主体的品类推荐；Q2=questions[1] 是品牌风险直问。可见度/提及率/首位/前三/前五的分母仅 Q1 成功回答。Q2 只用于风险、舆情和信任，不进入排名。平均位次只在 Q1 有供应商有效位次的回答内计算；未提及与提及但无排名分别保留。若输入提供 calculatedMetrics，优先引用其冻结数字，不另算相冲突口径。

citationList 对应实际引用，referenceList 只是检索参考，两者不能混算。信源分析按 URL 唯一文章、域名、平台、问题分别呈现。引用频次不是权威性，未读取源文章不推断其品牌提及。没有真实结构化竞品或分类排名时，明确缺失，按平台/问题做分类对照，禁止造榜。情感分类只依据供应商对监测主体的 nature/context，未分类不变成中性；风险指控必须核验，不能作为事实。

## 报告组装
全景完整承接 S1 事实、S2 营销图谱、S3 趋势、S4 定位与差异化矩阵、S5 诊断、S5.5 语义与信源、S6 话语、S7 视觉、S8 12 周日历、紧随日历的 S9.8 标题钩子、S9 行动方案。S4.8 是过程文件，不重复作为客户研究章节。S8 问答树/矩阵/标准答案可保留中间文件，不进入客户主报告。不要生成“危机与错误信息回应模板”“下游注入规则”“重校触发条件”等内部执行章节。不得暴露本地路径、令牌、运行配置或把阶段文件名当客户正文。

汇报沿用原商业逻辑，并融合诊断报告的整体/分类排名、舆情、信源、明细和指标解释；不是重新压缩成阶段摘要。所有实测指标统一从 monitoring 派生。3/6 个月目标明确标为“方案设定值，需以后续复测验证”，不可保证商业结果。HTML 保留中文、长表格、完整文字、自包含样式、锚点导航；窄屏允许表格横滚而非裁掉内容。S11 只整理格式，不删研究正文。
