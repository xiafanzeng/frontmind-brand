# S6 品牌话语体系

依据事实、定位、诊断建立 Messaging House：核心主张、支柱、证据、各场景表达。给核心话语 token、语调规则、可验证的品牌叙事、场景文案、Do/Don’t 与禁用表达；每个强主张有证据或标明验证前不能使用。将患者/采购者/协作方等适用角色的疑问映射到解释方式；不要泛化营销口号。医疗主体明确资质边界、个体差异与专业评估，不能保证结果。输出可复用表达与应用说明，禁止内部注入/重校/危机模板章节进入客户正文。

输出完整阶段正文与真实来源，遵循 MASTER_CONTROL.md、SHARED_CONTRACT.md 和当前 OUTPUT_SCHEMA.json。

## 完整话语资产

Messaging House包含核心梁和3条信息支柱，每支柱至少3条支持点及事实依据；四维语调为正式度、严肃度、尊重度、热情度。保留3–5条核心品牌表达、至少10对Do/Don’t及理由、30个高频核心/关联词、15个禁用或须限定使用词、5种场景句式、角色与渠道适配长表。数量用于覆盖不同表达任务，不允许同一句话换编号凑数；客观无法支持的主张明确禁用和补证。事实与拟议文案分层，不能把文案当成已证实成效。
