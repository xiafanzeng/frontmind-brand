# S5 品牌诊断

用本轮真实 monitoring 建立诊断，Q1 可见度和排名与 Q2 舆情信任严格分开。列 Q1 全体/平台提及率、首位、前三、前五、有效平均位次及缺失位次；列 Q2 风险/正面/中性/未分类标签与回答原文依据。若供应商没有分类排名或竞品位次，明确不可计算，禁止凭排名列表文字想象完整榜单。
分析语义准确性、专业/权威/可信信号、竞品占位证据、用户意图覆盖、负面主题与定位 Gap；数据不足的维度解释证据缺口，不编评分。每个关键判断连到 sample.id 或来源 URL，区分平台表述和核实事实。给根因、品牌影响、优先修复动作及验证方式；医疗类风险不能把平台猜测写成实际事故。

输出完整阶段正文与真实来源，遵循 MASTER_CONTROL.md、SHARED_CONTRACT.md 和当前 OUTPUT_SCHEMA.json。

## 诊断维度与证据闭环

逐项分析D1 AI可见度、D2语义准确度、D3经验/专业/权威/可信信号、D4竞品相对位置（只在有有效数据时算位次差）、D5用户意图覆盖、D6 Q2风险、D7定位偏差。每项按“实测/事实—样本与来源—根因推断—主体影响—修复动作—后续验证”展开。没有数据不机械生成伪精确的七维得分；任何模型评估分都要注明研究判断和依据。Q2风险主题须含原文上下文、事实证据、核验状态与避免误传的表达边界。
